VL Connector for PolyWorks - User Guide

VL Connector starts AI Replay in the KEYENCE VL Application, exports the scan as an STL file and has PolyWorks|Inspector evaluate it against the part template: alignment to the CAD, all controls of the template, a color map, the OK or NOK verdict, a PDF report in PolyWorks' standard layout and a CSV table.

1. Scenarios

A - PolyWorks on the scanner PC. The operator opens the part template in PolyWorks|Inspector and presses Measure. VL starts AI Replay for the part; the operator scans as usual. After the last position the STL goes straight to PolyWorks, which evaluates it and shows the verdict and the report.

B - PolyWorks on another PC. The scanner PC has only VL and VL Connector. The operator scans with AI Replay in VL as usual; the VL Connector agent in the background exports the STL and sends it to a shared network folder. A PolyWorks station evaluates it with the template of the VL program, and the PDF report comes back and opens on the scanner PC - only the reports of scans made on that PC.

2. Installation

You need Windows 10 or 11, the VL Application 4.6 with its English user interface (scanner PC) and PolyWorks Metrology Suite 2026 (evaluating PC). The installation needs administrator rights once (Windows asks); using VL Connector does not. Nothing is copied into the program folders of VL or PolyWorks (VL Connector is not a PolyWorks plug-in).

  1. Check that the SHA-256 of the downloaded ZIP matches SHA256SUMS.txt: Get-FileHash .\VLConnector-1.0.0-rc11.zip in PowerShell.
  2. Extract the ZIP (right click > Extract All) and double-click Install.cmd.
  3. The installer checks every file against its manifest and shows the package fingerprint. Compare it with the fingerprint published with the package, then confirm. Windows asks for administrator rights.
  4. It installs to C:\Program Files\VLConnector, which only administrators can change, with the PolyWorks button files and the Start menu entries VL Connector (settings), VL Connector agent and Uninstall VL Connector for all users of the PC. IT can install it silently and set the machine settings at the same time (see the Notes for IT).
  5. At the end it offers the setup wizard (also later: settings window > Setup > Setup wizard). The wizard asks for the scenario and the main options, adds the VL Connector tab with the Measure or Station button to PolyWorks (open PolyWorks|Inspector first; your PolyWorks layout is saved before and the wizard can undo it) and, for the network scenario, sets the shared folder and the agent.

Update: run Install.cmd of the new version. Settings and the PolyWorks buttons stay; the previous version is kept in C:\Program Files\VLConnector.old. If a VL Connector window or a scan is still running, the installer asks you to close it first. From 1.0.0-rc10 (installed in C:\ProgramData\VLConnector): the installer moves it; PolyWorks buttons and shortcuts made for the old folder keep working. Confirm the stage rotation automatically is off afterwards for everybody, until an administrator switches it on (section 3). Check an installation: Install.cmd -Verify (in the program folder) checks all files, the permissions of the folder and shows the status of the PC. Uninstall: Start menu > Uninstall VL Connector (administrator). Scans, reports and PolyWorks projects are never removed.

3. The settings window

Start menu > VL Connector. Every change is saved immediately ("Saved" appears at the bottom). Settings that the administrator set for all users of the PC are shown greyed out ("Set by the administrator for all users of this PC"); a note at the top says so.

PageWhat you set
SetupScenario A or B; in scenario B whether this PC is the scanner PC or the PolyWorks station. The status list checks this PC and offers the next step (for example Locate when the VL Application is not found). Setup wizard runs the guided setup again.
ScanningAI Replay mode (High speed, Standard, or let the operator choose in VL), export right after the scan, the automatic confirmation of the stage rotation (shown; changed only by an administrator), what happens to the VL window after the export, where VL programs are.
PolyWorksWhich measured pieces to keep, opening the PDF, the Measure (or Station) button.

Scanning options in detail

  • Replay mode - High speed is faster; Standard lets you confirm the stitching in VL; Ask operator leaves the choice to the operator in VL's own dialog.
  • Export the STL right after the scan - about 20 s faster: the STL is exported in scanner coordinates and PolyWorks pre-aligns it automatically. Switch it off to export after VL's own CAD alignment.
  • Confirm stage rotation automatically - see Safety: the stage rotation below. Shown here; only an administrator can change it (Change (administrator), Windows asks for administrator rights).
  • VL window after the export - Leave VL open, Minimize VL, Close VL without saving or Save VL data (.vld4), then close. VL is closed only after the exported STL has been checked again (complete binary STL with the exported number of triangles); otherwise VL stays open and the log says why. VL is never terminated forcibly.
  • Bring the evaluation to the front - scenario A: after the export the PolyWorks window comes to the front.

Safety: the stage rotation

Before the turntable moves, VL asks The stage will rotate. Continue? or Return the stage to the origin?. Normally the operator answers in VL. An administrator can decide, for all users of the PC, that VL Connector answers these two questions with OK itself (settings window > Scanning > Change (administrator), or when IT installs it). It cannot be switched on by a user, per part or per template.

When it is on, every automatic answer is announced: a red warning window appears at the top of the screen (it never takes the keyboard focus and does not cover VL's question) with a sound, and only then VL Connector presses OK. Every automatic answer is written to the Windows event log.

VL Connector leaves the question to the operator when the screen is locked, when the PC is used through a remote desktop connection, when the VL version has not been tested with VL Connector, or when the warning window cannot be shown. Make sure nothing blocks the stage and nobody reaches into the scanner while it can rotate.

4. Part templates in PolyWorks

Each part needs a template project in a PolyWorks workspace: the CAD model, the features and comparison points with their tolerances (the controls), as for any PolyWorks inspection. VL Connector measures all controls of the template and aligns the scan by automatic pre-alignment plus best-fit to the CAD.

Add these project properties to the template (File > Project > Properties > Add):

PropertyRequiredValue
VL programyes (scenario A)Path to the AI Replay program of the part (.vld4).
VL optionsnoOptions for this part, e.g. -Mode Standard - see Options per part.
VL reportsnoFolder for PDF and CSV of this part (otherwise the workspace folder Reports).
VL test STLnoPath to an STL: the Measure button evaluates it without scanning (to try a template).

Save the template afterwards. Every measured piece is a copy of the template named <template>_<date>_<time>; the template itself is never changed. The piece gets the property VL template, so pressing Measure in an open piece starts the next part from the template again.

Report: the PDF uses PolyWorks' standard report layout: the table of all controls with a snapshot, then top and front views of the color map. The CSV (opens in Excel) has one line per control with nominal, measured, deviation, tolerances and result, and the verdict in its last line; its header names the STL and its SHA-256. PolyWorks shows the verdict after the evaluation (scenario A), the agent in its notification (scenario B).

Verdict rules. The verdict is OK only when every control has one of PolyWorks' results inside the tolerance (Within ... safe zone, or Within ... warning zone, shown as OK with a warning). It is NOK when a control is beyond its tolerance, was not measured, or has a result VL Connector does not know (named in the summary). There is no verdict (an error, the piece is kept for checking) when the template has no controls, when the alignment or the measurement failed in PolyWorks, or when the STL is not the one VL Connector exported. VL Connector evaluates controls on features and comparison points with a best-fit alignment to the CAD.

5. Scenario A: the Measure button

Add the button to PolyWorks (once per Windows user)

Automatically: open PolyWorks|Inspector (any project), then press Add to PolyWorks in the setup wizard or in the settings window, page PolyWorks. A ribbon tab VL Connector with the Measure button appears. Your PolyWorks visual layout is saved before (in %LOCALAPPDATA%\VLConnector\polyworks-layout); the wizard can undo it.

By hand instead:

  1. In the settings window, page PolyWorks, press Copy macro path.
  2. In PolyWorks|Inspector open File > Visual Layout > Customize > Customize.
  3. Tab Macro Scripts > Import, paste the path (C:\Program Files\VLConnector\VLC_Measure_Button.pwmacro) and confirm.
  4. Tab Customize Ribbon (or Quick Access Toolbar) > choose Macro Script Files > select VLC_Measure_Button > Add. As icon, use the file from Copy icon path (VLC_icon_32.png).

The button only calls the installed macro, so updates of VL Connector need no new import.

Measuring

  1. Open the part template (or the last measured piece of the part) in PolyWorks|Inspector.
  2. Press Measure. A progress window shows what VL is doing; Cancel stops the measurement in PolyWorks. AI Replay in VL is not stopped by it: finish or close it in VL.
  3. Scan the part in VL as usual (place the part, press Measure in VL for each position).
  4. After the last position the STL is exported, PolyWorks evaluates it (about 15-30 s) and shows the verdict. The PDF opens if this is switched on.

Keep measured pieces (page PolyWorks): Every piece, Only NOK pieces or None - the PDF and CSV are always kept. Pieces that are not kept are removed from the workspace after the report is created.

6. Scenario B: network folder, station and agent

The operator on the scanner PC works in VL as usual: AI Replay, choose the program (.vld4) in VL, scan. The VL Connector agent waits in the background and does the rest: after the last position it exports the STL (named <program>_<date>_<time>.stl), sends it to a shared folder, and opens the PDF report when the PolyWorks station has evaluated it.

Shared folder

Create a folder on a file server, e.g. \\fileserver\metrology\VLConnector. The scanner PCs need to create files in its subfolder jobs and to read reports and status; the station needs to change files in all subfolders (IT: the rights per folder are in the Notes for IT). In the settings window of every PC: page Setup > PolyWorks on another PC, page Network > enter the folder > Test - it checks exactly what this PC needs in its role. The station creates the subfolders jobs, work, reports, processed, failed and status on its first test.

Measurement Programs List

The station finds the PolyWorks template of a scan by its VL program. Page Network > Edit list opens the Measurement Programs List, the file programs.csv in the shared folder. One line per VL program, separated by semicolons; the first line is the header:

Program;Workspace;Template
ABC;D:\PolyWorks\Parts\Parts.pwk;ABC
Housing-12;D:\PolyWorks\Parts\Parts.pwk;Housing12
  • Program: the name of the AI Replay program, i.e. the .vld4 file name without .vld4 (Part.A.vld4 is Part.A). Upper and lower case do not matter; the name must match exactly otherwise.
  • Workspace: the full path of the PolyWorks workspace (.pwk) on the station; Template: the template project in it. Workspaces on a network path need the administrator's permission.

The Setup page names every line that cannot be used (missing values, = or quotes, a program listed twice - then neither line is used). Without its first line Program;Workspace;Template the list is not usable at all, and the station pauses until it is corrected.

The agent (scanner PC)

On the scanner PC set the role Scanner PC (page Setup). On page Network, switch on Start the agent with Windows and press Start now once. The agent shows the VL Connector icon in the notification area; its menu shows the state (waiting for AI Replay, station online or offline), opens the last report or the reports folder, and can pause or end the agent.

Then scan as usual. After each AI Replay the agent:

  1. exports the STL (with the options of page Scanning: right after the scan or after VL's alignment, and what happens to the VL window),
  2. saves it in Documents\VL Connector\Scans and sends it to the shared folder - if the folder is not reachable, it waits in a local outbox and is sent automatically later; a scan that cannot be sent five times is set aside with a notification (%LOCALAPPDATA%\VLConnector\outbox\failed, with the reason),
  3. shows a notification when the station has evaluated it (OK / NOK; several results in one note) and opens the PDF (setting Open my PDF reports automatically). Reports are saved in Documents\VL Connector\Reports. After a NOK the icon stays red until you open the report or choose Mark the NOK result as seen.

Only reports of scans made on this PC are opened. An AI Replay started by the Measure button of scenario A is never exported twice.

The PolyWorks station

On the station PC choose PolyWorks station in the setup wizard (or page Setup). Then, once, with PolyWorks|Inspector open: Add to PolyWorks in the wizard (or page PolyWorks) adds the tab VL Connector with the VL Station button (by hand: import VLC_Station_Button.pwmacro like the Measure button).

To run the station, open a PolyWorks|Inspector used only for the station (from the Workspace Manager as usual) and press VL Station. A small window shows the shared folder, the last job and a Stop button. The station takes the scans one by one (oldest first), opens the template of the VL program from the Measurement Programs List, evaluates the scan and sends the report back; it uses the PolyWorks settings of the station PC (keep pieces, color scale). Keep the station PC logged on (a locked screen is fine) while scanning. When a problem stops it - for example an unusable Measurement Programs List - its window shows Paused with the reason and the agents show station paused; it continues by itself once the problem is solved. A scan that cannot be evaluated is reported to its scanner PC with the reason; none stays unanswered (after network.jobTimeoutMin, 15 minutes by default, a scan a station did not finish is reported as failed).

7. Options per part

The template property VL options (scenario A) overrides the settings for one part. (In scenario B the operator starts AI Replay in VL, so the settings of the scanner PC apply.) Use any of:

OptionValues
-ModeHighSpeed, Standard, Ask
-ExportImmediatelyOn, Off
-AfterExportNone, Minimize, Close, SaveAndClose
-ReturnFocusOn, Off
-TimeoutMinminutes to wait for the scan, 1 to 600 (default 45)
-SettleSecseconds to wait before the export, 0 to 60 (default 2)
-NewWindowalways open a new VL window

Example: -Mode Standard -AfterExport Minimize. An unknown option or a value out of range stops the scan with a clear message. The stage confirmation is not an option per part (only the administrator sets it for the PC); -ConfirmStageMotion in a template stops the scan with a message saying so.

8. Troubleshooting

Message or problemWhat to do
The scanner is not connectedCheck the scanner cable and power, then start again.
Another scan is running on this PC / VL is open but not idle on its start screenFinish or close the work in VL first; VL Connector never opens a second VL window.
VL Connector could not start the scan / stopped unexpectedly (in PolyWorks)The launcher gave no sign of life; the log (page Diagnostics) says why. Finish or close AI Replay in VL, then press Measure again.
The stage question was not answered automaticallyExpected when the screen is locked, in a remote desktop session, with an untested VL version or when the setting is off. The Windows event log (source VL Connector, event 1101) names the reason.
VL Connector is in use (installation)Close the VL Connector windows and let running scans finish, then install again.
The button file ... is missingThe installation is incomplete: an administrator runs Install.cmd of the package again.
Project ... has no VL programAdd the project property VL program to the template (section 4).
VL Connector could not start (in PolyWorks)Open the settings window: the Setup page shows what is missing.
PowerShell runs in ConstrainedLanguage modeAsk IT: VL Connector needs FullLanguage mode (see Notes for IT).
Template ... could not be openedThe template name or workspace is wrong, or the template is open in another PolyWorks.
Scenario B: no STL after AI ReplayIs the agent running (icon in the notification area)? Settings > page Network > Start now.
Scenario B: station offline in the agent menuStart the station (VL Station button) and check the shared folder on the station PC.
Scenario B: station paused in the agent menuThe station window shows the reason (e.g. the Measurement Programs List); correct it, the station continues.
Scenario B: Scan not sentThe scan could not be sent five times; the reason is in the notification and in %LOCALAPPDATA%\VLConnector\outbox\failed. Scan the part again once the cause is solved.
Scenario B: no report arrivesThe station is busy or stopped; the scan is evaluated as soon as it runs.
Scenario B: not in the Measurement Programs ListAdd the VL program (the .vld4 name without extension) to the list (page Network > Edit list).
VL does not react to VL ConnectorVL must show its English user interface; close extra dialogs in VL.

Logs: %LOCALAPPDATA%\VLConnector\logs (page Diagnostics > Open folder), one file per day and part of VL Connector, kept for 30 days.

9. Support

VL Connector is not official software. You can try contacting your local sales engineer, who can forward questions to the local technical team. Please attach the support ZIP: settings window > Diagnostics > Create ZIP. It holds the logs of the last 14 days (they name parts, verdicts, Windows users, computers and folders), the settings (yours and the administrator's), the status check and the versions - no scans, reports or PolyWorks data. Look into it before you send it.
